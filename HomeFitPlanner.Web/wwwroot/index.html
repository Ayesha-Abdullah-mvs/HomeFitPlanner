📚 DSA Concepts Applied to Auth

1. Separate Chaining Hash Table (O(1)):

User credentials reside in an array of singly linked lists. Time complexity is O(1 + α) where load factor α = N/M. Rehashing triggers if α exceeds 0.75.

2. Prefix Tree Trie (O(L)):

Usernames form paths of character nodes. Traversal takes O(L) steps (L = length), ensuring instantaneous availability verification without scanning the database.

3. Constant-Time Salted SHA-256 (O(1)):

Passwords are salted with 16 cryptographically secure bytes and compared with FixedTimeEquals to eliminate timing side-channel vulnerabilities.
